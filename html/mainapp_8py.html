Detailed Description

Tool for signing and verifying PDF files using PAdES-like RSA signatures.

This module enables the detection and decryption of private keys stored on USB devices, signing of PDF files by embedding a digital signature in metadata, and verification of these signatures using a public RSA key.

It includes a GUI built with Tkinter for signing and verifying in separate tabs.
